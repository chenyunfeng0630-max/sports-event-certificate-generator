A privacy-first TypeScript toolkit and CLI for generating accessible, verifiable SVG certificates for sports events. It turns a small CSV file into deterministic certificate files and a machine-readable manifest without putting recipient names in file names or logs.

![Fictional certificate generated by the example](examples/sample-certificate.svg)

## Why this project exists

Many community sports events still create certificates manually or build one-off scripts around spreadsheets containing unnecessary personal data. This project provides a reusable core with safer defaults:

- deterministic certificate numbers for idempotent reruns;
- bilingual English and Simplified Chinese output;
- dependency-free runtime and portable SVG files;
- XML escaping and HTTPS verification-link validation;
- deliberate refusal of phone, email, address, government-ID, password, token, and secret columns;
- name-free file names, manifests, and console output;
- overwrite protection, tests, CI, CodeQL, and a sensitive-information check.

## Quick start

Requires Node.js 20 or newer.

```bash
npm install
npm run verify
npm run example
```

The example writes two fictional certificates to `examples/output/`.

Use the CLI with your own data:

```bash
npm run build
node dist/src/cli.js generate \
  --input ./participants.csv \
  --config ./config.json \
  --out ./generated
```

After installing the package globally or linking it locally, the same command is available as `sport-cert`.

## CSV format

Required columns:

| Column | Meaning |
| --- | --- |
| `recipientId` | Opaque identifier such as `athlete-001`; never use a phone number, email, or government ID |
| `recipientName` | Name rendered on the certificate |
| `achievement` | Award, result, completion, or recognition text |

Optional columns: `category`, `eventDate`, and `verificationUrl`.

```csv
recipientId,recipientName,achievement,category,eventDate,verificationUrl
athlete-001,Sample Athlete,Gold Medal,Open Division,2026-08-08,https://example.org/certificates/athlete-001
```

## Configuration

```json
{
  "eventName": "Open Community Games 2026",
  "issuer": "Open Sports Foundation",
  "title": "Certificate of Achievement",
  "subtitle": "Celebrating participation, progress, and sportsmanship",
  "issueDate": "2026-08-08",
  "locale": "en",
  "idPrefix": "OCG",
  "namespace": "open-community-games-2026",
  "theme": {
    "primary": "#12355b",
    "accent": "#e08d2d",
    "background": "#f7f4ec"
  }
}
```

Use `"locale": "zh-CN"` for Chinese labels. The theme also accepts `text`, `muted`, `fontFamily`, `width`, and `height`.

## Library API

```ts
import { generateCertificates, parseCertificateCsv } from "sports-event-certificate-generator";

const records = parseCertificateCsv(csvText);
const certificates = generateCertificates(records, {
  eventName: "Open Community Games 2026",
  issuer: "Open Sports Foundation",
  idPrefix: "OCG",
});
```

## Privacy and security

The generator intentionally accepts only the fields required for a certificate. Do not put identity documents, phone numbers, email addresses, home addresses, medical information, account credentials, or API keys in source files, CSV files, manifests, issue reports, or pull requests.

Recipient names must still be treated as personal data. Keep input CSV files and generated certificates private unless participants have consented to publication. See [Privacy by design](docs/privacy.md) and [Security policy](SECURITY.md).
